# Gothic Chess

Интерактивное веб-приложение с шахматами в готическом фэнтезийном стиле.

## Идея проекта

Основная часть приложения — шахматная доска, с которой пользователь может полноценно взаимодействовать: выбирать фигуры, видеть доступные ходы, перемещать фигуры, брать фигуры соперника и играть полноценную партию.

Планируется реализовать основные правила шахмат, очередность ходов, подсветку возможных ходов, историю партии и возможность начать игру заново.

Кроме основного режима игры, возможно добавление дополнительных механик. Например, отдельного шахматного тренажёра с готовыми позициями и небольшими задачами, в которых пользователю нужно будет найти правильный ход.

В дальнейшем также рассматривается возможность добавить режим игры против компьютера.

## Технологии

- HTML
- CSS
- JavaScript
- DOM API

Проект будет реализован на чистом JavaScript без использования frontend-фреймворков.
